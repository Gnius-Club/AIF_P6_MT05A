🎯 Objetivo de Aprendizaje

Los estudiantes podrán: comprender la percepción artificial y la toma de decisiones automatizada mediante la detección de señales de tránsito. Usar el Smart A.I. Lens y Micro:Bit para ejecutar movimientos con el robot XGO.

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Quiero aprender cómo usar visión con IA en el XGO para reconocer señales visuales usando Python. Explícame primero qué significa que un robot “perciba” con una cámara y cómo se convierte esa percepción en una decisión. Luego enséñame a activar el modo Card con ai.switch_function(Card) y a leer lo que detecta con ai.get_card_content(). Después guíame para conectar esa lectura con acciones físicas como avanzar o girar (xgo.move_forward y xgo.rotate_left). Incluye qué hacer si el robot no reconoce bien la señal: iluminación, distancia, ángulo o repetición del escaneo.

⚡ Puntos Esenciales de la Misión

🎓

Concepto Clave

Percepción Artificial: Es la capacidad de un robot para "ver" y entender su entorno usando una cámara, similar a cómo nosotros usamos nuestros ojos para reconocer objetos.

🔧

Habilidad Técnica

Usar la cámara inteligente para reconocer tarjetas y mover el robot XGO.

🧪

Experimentación

Probar con diferentes condiciones de iluminación y distancias de las tarjetas para entender limitaciones.

💬

Interacción con XOLO

XOLO ya conoce a cada estudiante y el tema de hoy. Solo abren el chat y comienzan a aprender. Tú guías el timing y motivación.

🚨 Resolución Rápida de Problemas

  • Si los alumnos no pueden ingresar a Gnius Space: Activa XOLO SOS en xolo.gnius.club para continuar la misión sin interrumpir la clase.
  • Si el XGO no se mueve: Verificar que la batería esté cargada y el interruptor en ON. Revisar la conexión del Micro:bit.
  • Si el Smart A.I. Lens no detecta las tarjetas: Revisar que el lente esté limpio y que haya buena iluminación. Probar ajustando la distancia entre la tarjeta y la cámara.
  • Si hay errores en el código: Recordar a los estudiantes que XOLO puede ayudar a depurar. Pídeles que copien el error y se lo muestren a XOLO.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear un proyecto en Python donde el XGO funcione como un “robot guía” que sigue señales visuales tipo tránsito (avanzar, girar, detenerse) para recorrer una mini-ciudad. Quiero que el robot interprete al menos 3 señales diferentes y ejecute una acción distinta por cada una. Después genera el código en Python para ejecutarlo, de acuerdo a tu entrenamiento con el robot XGO y Micro:bit."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿El XGO realiza la acción correcta al mostrarle la tarjeta?
  • ¿Qué pasa si inclinas la tarjeta o la alejas demasiado de la cámara?
  • ¿Funciona igual el reconocimiento con mucha luz vs. poca luz?
  • ¿Por qué decimos que el robot está "percibiendo" y no solo "viendo" como una cámara normal?
  • ¿Qué tan confiable crees que es el robot para tomar decisiones solo en una ciudad real?

¡Es hora de crear, genios! Ahora vamos a usar lo aprendido para que nuestro XGO sea un robot guía autónomo. Primero, platiquen con XOLO usando el prompt de la pantalla para idear su proyecto. Una vez que tengan su GCS, tradúzcanlo a bloques en MakeCode. Por ejemplo, podrían programar que al ver la señal de "Giro", el XGO haga un baile y luego rote. Prueben primero en el simulador y luego pasen al hardware real. No olviden usar las preguntas de experimentación para ver qué tan listo es su robot. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar.
